About Me

Hi! I’m Leila, a web developer with a passion for geospatial tech, real-time visualization, and sustainable solutions. I enjoy designing tools that help people understand the world around them. I work in tech because the web is a powerful tool for communcating ideas. After my family was freed from living under dictatorship in the 2012 Arab Spring, I became interested in web technologies. After a few formative side quests as a climate educator and ceramics artist, I turned my professional attention to web development in 2020.

About This Site

I believe in the web as a space where everyone is meant to contribute. This site is a node process being served from a retired 2018 Mac Mini running Ubuntu sitting on my desk. I poked a hole in my home Wi-Fi network and use a cron job to keep DNS records up to date with GoDaddy.

The goal was to use as few out-of-the-box solutions as possible to get a site live. It’s simple, but in a time of hosted pages and cloud compute, it’s important to remember where it all started.
